# 게임 클래스 패치

원작 jar는 저장소에 없고(릴리스 `skt-pkg`의 `hero2.zip`), 빌드 때 `tools/patch_game.py`가 패키지 안의 jar를 열어
아래 바이트 패치를 적용한 뒤 `build/web/game/hero2.zip`으로 내보낸다. 각 패치는 "해당 클래스 안에서 정확히 한 번
나오는 바이트열"을 찾아 같은 길이로 바꾸는 방식이라 클래스 파일 구조(상수 풀, 코드 길이)를 건드리지 않는다.
패턴이 0번 또는 2번 이상 잡히면 빌드가 실패한다. 32바이트 SKT 래퍼 헤더는 그대로 둔다(wie는 앞 8바이트만 본다).

참고 소스: scratchpad `research/cfr/영웅서기2/*.java` (CFR 디컴파일). 바이트 위치는 `javap -c`나 패턴 검색으로 찾는다.

| 클래스 | 바이트 | 효과 | 근거 |
|---|---|---|---|
| `cd.class` | `10 64 a4` → `10 01 a4` (bipush 100 → 1, 뒤는 if_icmple) | 핸즈온 스플래시가 1틱 뒤 자동으로 타이틀로 넘어감 | `cd.b(Graphics)`: `if (this.a > 100) a((byte)1)` |
| `cd.class` | `10 1e a4` → `10 00 a4` (bipush 30 → 0) | 스플래시 중 키 입력이 즉시 먹음 | `cd.keyPressed`: `if (this.a <= 30) break;` |
| `bg.class` | `10 09 b7` → `10 04 b7` (super(null, 9) → 4) | 타이틀 메뉴 9항목 → 4항목: 새로하기 · 이어하기 · 환경설정 · 도움말. 네트워크창고 · 네트워크대전 · 선물하기 · 껨존가기(모두 WAP 접속) · 게임종료 제거 | `bg.<init>`: `super(null, (byte)9)` = 항목 수, 라벨은 `com.tdf` 0..8 순서 |

## 측정 (2026-10-16, 새로고침 뒤 시작하기 활성까지)

패치 전 4.9초 → 패치 후 2.4초. 남는 2.4초는 게임 자체 초기화(리소스 로드)와 타이틀 전환.

## 후보 (아직 안 함)

- 대화창 `#SKIP` 글자: 스프라이트. 디코더가 생기면 투명 이미지로 교체하거나 그리기 호출을 nop.
- 도움말 "기본 조작" 텍스트(`t/help.tdf`)의 키 설명을 패드 기준으로: 평문이라 같은 길이 안에서 바꾸거나 테이블 재작성.
- 타이틀 "PRESS ANY KEY": 우리 쪽에서 자동으로 넘기므로 그대로 둠.
