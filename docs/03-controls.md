# 조작 전체 목록 (키패드 기준)

출처: `t/help.tdf`의 "기본 조작" 항목과 디컴파일 소스의 키 핸들러
(필드 `bd.keyPressed/a(int,int)`, 이벤트 `ae.a(int,int)`, 타이틀 `bg.a(int,int)`, 메뉴 공통 `g.b/c/d/e`, 게임 메뉴 `ck`).
키 코드: 숫자키는 ASCII(48~57), `#`=35, `*`=42, CLR=8(wie `KeyCode::CLEAR`). 방향키·확인(게임액션 UP/DOWN/LEFT/RIGHT/FIRE)은 2/8/4/6/5와 항상 동일하게 처리된다.

게임이 실제로 쓰는 키는 **0~9, #, *, CLR** 13개. 이 중 5와 2/4/6/8은 방향·확인과 같다.

## 1. 필드 (탐험·전투) — `u.a == 3`

| 키 | 동작 | 비고 |
|---|---|---|
| 2 / 4 / 6 / 8 (방향키) | 이동 | 누르는 동안 이동. 공격 모션 중 입력은 다음 방향으로 예약 |
| 5 (확인) | 일반 공격 · 조사 · 대화 | NPC/이벤트 앞이면 대화·조사, 아니면 공격. 연타 = 콤보(n단) |
| 1 / 3 / 7 / 9 | 스킬 슬롯 1~4 | 등록된 **액티브 스킬** 또는 **야수 스킬**. 쿨타임 중·사망·이벤트 중 무시 |
| 0 | 회복 아이템 사용 | 현재 지정된 회복 아이템 1개 소모 |
| # | 회복 아이템 교체 | 다음 종류의 회복 아이템으로 전환 |
| * | 미니맵 | 평상시(이동 가능 상태)에만 |
| CLR | 게임 메뉴 열기 | 평상시에만 |

## 2. 대화 · 이벤트 — `u.a == 4` (`ae`)

| 키 | 동작 |
|---|---|
| 5 (확인) | 다음 대사 / 계속 |
| # | 이벤트 전체 스킵 (`#SKIP` 표시가 이것) |
| 4 / 6 | 선택지(예/아니오) 전환 |
| 5 | 선택 결정 |

그 외 상태: 획득·안내 팝업(`u.a == 11`)은 **아무 키**로 닫힘, 엔딩·스태프롤(12)은 **아무 키**로 넘김, 게임오버(14)는 **5**로 재시작.

## 3. 타이틀 — `u.a == 2` (`bg`, 텍스트 `t/com.tdf`)

| 키 | 동작 |
|---|---|
| 4 / 6 | 항목 좌우: 새로하기 · 이어하기 · 환경설정 · 도움말 · 네트워크창고 · 네트워크대전 · 선물하기 · 껨존가기 · 게임종료 |
| 5 | 선택 |

- 슬롯 선택(새로하기/이어하기): 4/6 슬롯 이동, 5 선택. 새 게임은 이어서 난이도(NORMAL · HARDCORE · HELL) 선택.
- 환경설정: 2/8 항목(사운드 · 배경음 · 효과음 · **게임속도** SLOW/NORMAL/FAST/FASTER · 시선이동), 4/6 값 변경, CLR 닫기.
- 네트워크 3종과 껨존가기는 WAP 접속이라 웹판에서 의미 없음.

## 4. 게임 메뉴 — `u.a == 5` (`ck`, 텍스트 `t/gm.tdf`), 필드에서 CLR

| 키 | 동작 |
|---|---|
| 2 / 8 | 항목 이동 (캐릭터 · 인벤토리 · 장비 · 스킬 · 야수 · 퀘스트 · 카드 · 시스템) |
| 5 | 들어가기 |
| CLR | 뒤로 / 닫기 |

하위 화면 공통(`g` 베이스 클래스):

| 키 | 동작 |
|---|---|
| 2 / 8 | 목록 위아래 (끝에서 순환) |
| 4 / 6 | 탭·열·페이지 이동, 수량 ±, 예/아니오 전환 |
| 5 | 선택 → 컨텍스트 팝업 |
| CLR | 팝업 취소 / 한 단계 뒤로 |

팝업 항목(gm.tdf): 사용하기 · 장비장착 · 장비해제 · 버리기 · 상세보기 · 포인트투자 · **1번에 등록 · 3번에 등록 · 7번에 등록 · 9번에 등록**(스킬/야수 스킬을 슬롯에 지정).
시스템: 세이브 · 도움말 · 옵션 · 종료하기. 저장은 보스맵에서 불가.

## 5. NPC 화면 — 상점(`o`, `t/shop.tdf`) · 대장장이(`bv`, `t/rf.tdf`) · 야수관리사(`cm`, `t/bm.tdf`) · `cq`(`t/bsm.tdf`)

모두 4번의 공통 규칙: 2/8 이동, 4/6 탭·수량, 5 선택, CLR 뒤로. 수량 입력은 4/6.

## 6. 스마트폰 재설계용 요약

플레이어가 실제로 구분해서 눌러야 하는 행동은 아래가 전부다.

| 행동 | 원래 키 | 쓰이는 곳 |
|---|---|---|
| 이동 / 커서 | 2 4 6 8 | 필드, 모든 메뉴 |
| 공격 · 확인 | 5 | 필드, 대화, 모든 메뉴 |
| 스킬 1~4 | 1 3 7 9 | 필드 |
| 회복 | 0 | 필드 |
| 회복 교체 **/ 대화 스킵** | # | 필드 / 대화 (같은 키, 다른 뜻) |
| 미니맵 | * | 필드 |
| 메뉴 열기 **/ 뒤로** | CLR | 필드 / 메뉴 (같은 키, 다른 뜻) |

- 스틱 하나가 2/4/6/8을 모두 대신하므로 메뉴에서도 스틱으로 커서를 옮기면 된다.
- 버튼은 최소 9개: 확인/공격, 스킬×4, 회복, #(회복 교체·스킵), 지도, 메뉴/뒤로.
- 게임이 키 이름을 화면에 쓰는 곳: 대화창 `#SKIP`(스프라이트), 도움말 텍스트(`help.tdf`), 스킬 등록 팝업 "1번에 등록…"(`gm.tdf`), HUD 슬롯 번호(스프라이트). 텍스트 둘은 평문이라 바로 고칠 수 있고 스프라이트 둘은 디코더가 필요하다.
